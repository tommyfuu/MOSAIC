MOSAIC · how to run

MOSAIC pipeline guide

Run MOSAIC on your own studies or on simulated data. To see how the results and figures are made, read the results vignette.

What it does

MOSAIC combines microbiome studies, removes batch effects with several methods, and compares how well each method worked.

PrepareClean and filter your data, or simulate new data.
CorrectRun ComBat-seq, limma, MMUPHin, ConQuR, Harmony, Percentile Normalization, DEBIAS-M and others.
EvaluateScore each method on diversity, differential abundance, prediction and runtime.

Install

conda env create -f env.yml
conda activate mic_data_integration

Then install MIDASim, FDboost and mixOmics in R. DEBIAS-M is optional: pip install DEBIAS-M.

Set sim_output_root in paths.yml to the folder where results should go.

Run on your own data

MOSAIC reads MicrobiomeHD and curatedMetagenomicData studies directly. For other data, make one folder per dataset with a *count_data.csv (taxa × samples) and a *meta_data.csv (one row per sample).

1. Make a config file

Copy config.yml (MicrobiomeHD) or additional_ymls/config_IBD.yml (curatedMetagenomicData) and change:

EntrySet it to
dataset_nameyour dataset; end it with _microbiomeHD or _CMD if it comes from there
srcthe folder with your data
datatypecount or relab
used_R_methodscount: combat_seq, limma, MMUPHin, ConQuR, ConQuR_libsize
relab: combat, limma, MMUPHin, ConQuR_rel
used_Python_methodsharmony, percentile_norm, plus debiasm if installed
covar, condition_valuethe condition column (e.g. disease) and its positive value
batch_refa reference batch
RW_LIBSIZE_THRESHOLDdrop the lowest-depth samples, e.g. 0.05
evaluation_outputswhere results go

2. Run

Put your config on the first line of Snakefile, set rules_to_run: 'all_rw', and run Snakemake. Or run each step yourself:

snakemake -c1                                                          # everything

python3 benchmark/evaluate.py -o 3 --config my_config.yml              # Python methods
python3 benchmark/evaluate.py -o 4 --config my_config.yml              # evaluation
python3 benchmark/evaluate.py -o 4 --config my_config.yml --rerun-rf   # prediction without leakage

The main result is global_benchmarking_stats_<dataset>.csv: one column per method, one row per metric.

Run simulations

All simulations, including every ablation, run from Snakefile_simulation. Pick scenarios in config_simulation_scenarios.yml or on the command line.

snakemake -s Snakefile_simulation -n                                   # preview
snakemake -s Snakefile_simulation --cores 4 --config run_scenarios=[zeroinf90] iterations=5
bash run_simulation_workflow.sh                                        # everything, on SLURM

Each replicate has its own seed. If a run stops, run the same command again to continue.

Outputs

<scenario>/data/                    simulated data and the true answers
<scenario>/output_count/            corrected data
<scenario>/eval_count/              scores for each replicate
<scenario>/summary_count.csv         mean and 95% CI over replicates
ablation_figures_count/             each ablation vs the baseline

evaluate.py options

-oRuns
3 / 4your own data: Python methods / evaluation
16 / 17any simulation scenario: Python methods / evaluation
1, 2, 5–9, 13–15the original manuscript runs and plots

Add --rerun-rf for prediction without leakage, and --succinct to plot only the main methods.

Literature check

For real data there is no ground truth. MOSAIC searches PubTator for each significant taxon together with five disease terms and counts how many are often reported with the disease. Treat it as a starting point, not as proof. See pubtator/README.md.

Test your install

bash benchmark/tests/test_simulation_workflow.sh

It takes about 3 minutes and ends with ALL TESTS PASSED.
